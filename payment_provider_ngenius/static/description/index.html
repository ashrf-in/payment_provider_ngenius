N-Genius Payment Provider

Accept online payments in Odoo with N-Genius Online.

Give customers a secure checkout experience and manage payment activity from Odoo.

What This App Does

This module adds N-Genius as a payment option in Odoo, so customers can complete their payment on a secure hosted payment page.

It is a good fit for businesses that already use N-Genius and want a smooth payment experience connected to their Odoo website checkout.

    Simple Configuration

    • Install the module in your Odoo database.
    • Open the N-Genius payment provider settings.
    • Add your API key and outlet reference.
    • Choose test mode or live mode.
    • Publish the provider and start accepting payments.
