What This App Is For

This module is made for businesses already using N-Genius through Network International and wanting a cleaner checkout connection with Odoo.

It adds N-Genius as a payment option, redirects shoppers to a secure payment page, and keeps the related payment flow connected to your Odoo sales process.

Simple Setup

  1. Install the module in your Odoo database.
  2. Open the N-Genius payment provider configuration.
  3. Add your API key and outlet reference.
  4. Select test mode or live mode.
  5. Publish the provider and start accepting payments.

Requirements

This app requires an active N-Genius merchant account from Network International and valid credentials. It is intended for businesses that want to connect their existing payment service with Odoo.
