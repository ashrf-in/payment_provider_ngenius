N-Genius Payment Provider

Accept online payments in Odoo with N-Genius Online by Network International.

Connect your Odoo checkout to a secure hosted payment flow and manage payment activity from Odoo.

What This App Does

This module adds N-Genius as a payment option in Odoo, so customers can complete their payment on a secure hosted payment page.

It is built for merchants already using Network International and looking for a smooth, connected checkout experience inside Odoo.

Main Benefits

Secure Checkout

Customers pay through the hosted N-Genius payment page.

Easy Setup

Configure your N-Genius credentials from the Odoo payment provider screen.

Payment Visibility

Track payment updates directly inside Odoo.

Full Refunds

Refund eligible transactions from Odoo when needed.

Simple Configuration

  • Install the module in your Odoo database.
  • Open the N-Genius payment provider settings.
  • Add your API key and outlet reference.
  • Choose test mode or live mode.
  • Publish the provider and start accepting payments.

Included Features

Hosted Payment Flow

Redirect customers to a secure payment page managed by N-Genius.

Sandbox and Live Modes

Test your setup before going live with real transactions.

Automatic Status Updates

Keep Odoo payment information up to date after checkout.

Full Refund Support

Manage full refunds from Odoo for supported transactions.

Important Note

This app requires an active N-Genius merchant account from Network International and valid credentials. It is intended for businesses that want to connect their existing payment service with Odoo.
