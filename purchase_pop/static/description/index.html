Point of Purchase (POP) Terminal

A touch-optimized, high-speed ordering interface for Odoo 19

Touch-First Design

Optimized for warehouse tablets, kiosks, and mobile devices with a specialized numpad interface.

Smart Logistics

Multi-warehouse support with precise delivery picking type selection for every order.

PO Append Mode

Don't just create new orders—seamlessly find and update existing draft POs for specific vendors.

Deep-Dive Features

Vendor Intelligence Integration

Automatically synchronized with Odoo's Pricelists and Supplier Info. See real-time vendor pricing, discounted rates, and Minimum Order Quantities (MOQ) as you type.

Dynamic Inventory Visibility

Never over-order. The terminal displays real-time forecasted and available quantities for every product, filtered by your selected warehouse.

Categorized Discovery

Search through thousands of products easily using a deep Recursive Category Tree sidebar and high-speed global search.

Safety & Protection

Built-in logic prevents reducing quantities of items that have already been partially or fully received, ensuring database integrity.

Modern & Responsive Experience

Designed for the modern warehouse, our terminal works flawlessly on any device. Whether you're on a stationary desktop kiosk or walking the floor with a tablet, the interface adjusts to provide the most efficient viewport for your operations.

  • Full-screen mode for dedicated kiosk use
  • Gesture-based basket management (swipe to delete)
  • Adaptive grid system for various screen sizes
